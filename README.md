<h1 align="center">im-just-a-dev</h1>

<p align="center">Simple skills for common dev operations. Should come in handy in agentic use.</p>

Chain skills in one request:

```text
/git sync remote then /branch create new and /pr new on it with X feature
```

`git` synchronizes the starting branch. `branch` creates the work branch from that base. `pr` completes the requested feature, validates it, and opens or reuses the PR.
